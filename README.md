# 이메일 할일관리 (Email Task Tracker)

이메일을 붙여넣으면 마감일을 자동으로 찾아내고, Claude Desktop/Code에 바로 붙여넣을 수 있는 실행 프롬프트를 만들어주는 할일관리 웹앱입니다.

**바로 열어보기**: https://email-task-tracker-kwangmin-ryu.vercel.app

---

## 1. 이 앱의 핵심 아이디어

브라우저로 열리는 웹사이트는 내 컴퓨터의 실제 파일이나 폴더를 직접 읽거나 쓸 수 없습니다. 그래서 역할을 이렇게 나눴습니다.

| 구분 | 역할 |
|---|---|
| **이 웹사이트** | 할일 상태(진행중/완료/보류/취소)를 관리하는 "기준판". 상태 변경은 여기서 수동으로 함 |
| **내 컴퓨터의 폴더** | 실제 파일들이 보관되는 곳 (이 사이트는 그 폴더 안을 들여다보지 않음) |
| **Claude Desktop/Code** | 이 사이트가 만들어준 프롬프트를 사람이 직접 붙여넣으면, 그 순간 실제로 파일을 정리하고 간단한 작업을 처리하는 실행 담당 |

### 사용 흐름
1. 이메일 내용을 이 사이트에 붙여넣는다 (관련 파일이 있으면 파일명/경로도 같이 적어둔다 — 파일 자체를 올리는 게 아니라 "이런 파일이 있다"는 메모만 남기는 것)
2. 사이트가 이메일에서 마감일을 자동으로 찾아본다
   - 찾으면 자동 저장, 못 찾으면 바로 입력창이 뜬다
3. 사이트가 이 정보로 **AI 실행 프롬프트**를 만들어준다 → "복사" 버튼으로 복사
4. 그 프롬프트를 Claude Desktop나 Claude Code에 붙여넣는다
5. Claude가 그 자리에서 파일 정리, 요약, (가능하면) 간단한 답장 초안 작성 등을 실제로 처리한다
6. 사이트로 돌아와서 할일 상태를 진행중 → 완료 등으로 직접 바꿔준다

## 2. 중요: 데이터는 이 브라우저에만 저장됩니다

이 앱은 별도의 서버나 로그인 계정이 없습니다. 모든 할일 데이터는 **지금 사용 중인 브라우저의 저장공간(localStorage)** 에만 저장됩니다.

- 같은 브라우저·같은 기기에서는 새로고침하거나 다시 접속해도 데이터가 그대로 남아있습니다.
- 다른 브라우저, 다른 기기, 시크릿(비공개) 모드에서는 데이터가 보이지 않습니다 (동기화 안 됨).
- 브라우저 저장공간/방문 기록을 지우면 데이터도 함께 사라집니다.

한 사람이 한 기기/한 브라우저에서 꾸준히 쓰는 용도에 맞는 구조입니다. 여러 기기에서 같이 쓰려면 나중에 서버 저장 방식(계정 로그인 + 데이터베이스)으로 바꾸는 작업이 추가로 필요합니다.

## 3. 화면 구성

- **상단 바**: 설정 / 프로젝트 관리(추가·삭제) / 빠른 할일 추가 / 이메일로 추가
- **상태 탭**: 전체 / 진행중 / 완료 / 보류 / 취소 — 클릭해서 해당 상태만 모아보기
- **필터**: 프로젝트별, 마감기한별(기한 지남/오늘 마감/7일 이내/기한 없음)로 좁혀보기
- **할일 카드**: 클릭하면 상세 화면 — 이메일 원문, 생성된 프롬프트(다시 복사 가능), 상태 변경 버튼, 상태 변경 이력(타임라인, 길어지면 내부 스크롤)이 모두 보입니다
- **프로젝트 삭제**: "+ 프로젝트" 모달에서 기존 프로젝트를 삭제할 수 있습니다. 삭제해도 그 프로젝트에 속한 할일은 지워지지 않고 "프로젝트 없음" 상태로 남습니다.

### 관련 파일은 따로 입력하지 않습니다
파일명/경로를 앱에 직접 입력하는 기능은 없습니다 — 실제로 Claude Desktop/Code에 프롬프트를 붙여넣을 때 파일도 함께 첨부해서 보내면 되기 때문입니다. 대신 이메일 본문에 "첨부", "파일", "문서" 같은 단어나 확장자(`.pdf`, `.docx` 등)가 보이면, 등록 완료 화면과 상세 화면에 "파일 첨부를 잊지 마세요" 알림이 자동으로 뜹니다.

## 4. 할일 상태 규칙

진행중 / 완료 / 보류 / 취소 네 가지 상태는 **서로 자유롭게 오갈 수 있습니다**. "취소"도 완전 삭제가 아니라 상태 중 하나일 뿐이라, 나중에 다시 "진행중"으로 되돌릴 수 있습니다. 상태가 바뀔 때마다 시간이 자동으로 기록되어, 나중에 "완료까지 며칠 걸렸는지", "몇 번 보류됐는지"를 상세 화면의 타임라인에서 확인할 수 있습니다.

## 5. 마감일 자동 인식 / 제목 자동 생성에 대해

- **마감일 인식**: `2026-09-20`, `9월 20일까지`, `9/20`, `오늘`/`내일`/`모레` 같은 흔한 표현을 규칙 기반으로 찾아냅니다. 완벽하지 않으니, 못 찾으면 즉시 직접 입력을 요청합니다.
- **제목 자동 생성**: 실제 AI(생성형 언어모델)를 호출하는 게 아니라, "인사말 줄은 건너뛰고 첫 번째 의미 있는 문장을 제목으로 쓴다"는 간단한 규칙으로 만듭니다. 상세 화면에서 필요하면 나중에 직접 다듬어 쓸 수 있습니다 (현재는 제목 수정 기능은 없고, 재등록으로 대체 — 필요하시면 추가 제작 가능합니다).

## 6. 설정 — 데스크탑 할일 폴더 경로

상단의 "설정"에서 내 컴퓨터의 폴더 경로(예: `C:\Users\내이름\Desktop\할일`)를 적어두면, 생성되는 프롬프트 안에 "이 경로 아래에 정리해줘"라는 안내 문구로 그대로 들어갑니다. 이 사이트가 실제로 그 폴더에 접근하는 건 아니고, Claude에게 전달할 안내 문구를 미리 채워주는 역할만 합니다.

## 7. 로컬에서 열어보기 / 수정하기

빌드 과정이 필요 없는 순수 HTML/CSS/JS입니다.

```bash
cd "C:\Users\etners\Desktop\ETNS_VIBE\email-task-tracker"
python -m http.server 8090
```
브라우저에서 `http://127.0.0.1:8090` 접속.

파일 구성:
```
email-task-tracker/
├── index.html   # 화면 구조 + 모든 모달(팝업)
├── style.css    # 디자인
└── app.js       # 모든 동작 로직 (저장/불러오기, 날짜 파싱, 프롬프트 생성 등)
```

## 8. 앞으로 확장하고 싶다면

- 여러 기기에서 동기화하고 싶다면 → 로그인 + 서버 데이터베이스(예: Supabase) 도입 필요
- 제목/요약을 진짜 AI가 만들게 하고 싶다면 → 별도 백엔드에서 언어모델 API를 호출하는 구조 추가 필요 (API 키를 브라우저에 직접 노출하면 안 되기 때문)
- 파일을 실제로 첨부/열람하고 싶다면 → 별도 파일 저장소(예: 클라우드 스토리지) 연동 필요
