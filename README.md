# 이메일 할일관리 (Email Task Tracker)

이메일을 붙여넣으면 마감일을 자동으로 찾아내고, Claude Desktop/Code에 바로 붙여넣을 수 있는 실행 프롬프트를 만들어주는 할일관리 웹앱입니다.

**바로 열어보기**: https://email-task-tracker-kwangmin-ryu.vercel.app

---

## 1. 이 앱의 핵심 아이디어

브라우저로 열리는 웹사이트는 내 컴퓨터의 실제 파일이나 폴더를 직접 읽거나 쓸 수 없습니다. 그래서 역할을 이렇게 나눴습니다.

| 구분 | 역할 |
|---|---|
| **이 웹사이트** | 할일 상태(진행중/완료/보류/취소)를 관리하는 "기준판". 상태 변경은 여기서 수동으로 함 |
| **내 컴퓨터의 폴더** | 실제 파일들이 보관되는 곳 (이 사이트는 그 폴더 안을 들여다보지 않음) |
| **Claude Desktop/Code** | 이 사이트가 만들어준 프롬프트를 사람이 직접 붙여넣으면, 그 순간 실제로 파일을 정리하고 간단한 작업을 처리하는 실행 담당 |

### 사용 흐름 (수동)
1. 이메일 내용을 이 사이트에 붙여넣는다
2. 사이트가 이메일에서 마감일을 자동으로 찾아본다
   - 찾으면 자동 저장, 못 찾으면 바로 입력창이 뜬다
3. 사이트가 이 정보로 **AI 실행 프롬프트**를 만들어준다 → "복사" 버튼으로 복사
4. 그 프롬프트를 Claude Desktop나 Claude Code에 붙여넣는다
5. Claude가 그 자리에서 파일 정리, 요약, (가능하면) 간단한 답장 초안 작성 등을 실제로 처리한다
6. 사이트로 돌아와서 할일 상태를 진행중 → 완료 등으로 직접 바꿔준다

`automation/` 폴더의 자동화 스크립트를 설정하면 4~5번(프롬프트 복사 → 붙여넣기)이 자동으로 실행됩니다. 자세한 내용은 9번 항목 참고.

## 2. 계정별로 서버에 저장됩니다

처음엔 브라우저에만 저장하는 구조였지만, 지금은 회원가입/로그인이 있고 데이터는 서버(Supabase Postgres)에 계정별로 저장됩니다.

- 같은 계정으로 로그인하면 어느 기기·어느 브라우저에서든 같은 할일 목록을 볼 수 있습니다.
- 다른 계정으로 로그인하면 서로의 할일이 보이지 않습니다 (완전히 분리).
- 비밀번호는 암호화(해시)해서 저장하며, 원문 그대로는 저장하지 않습니다.

| 구성요소 | 역할 |
|---|---|
| GitHub | 코드 저장소: https://github.com/fbrhkdals/email-task-tracker |
| Vercel | 앱 실행/배포 (서울 리전) |
| Supabase | 계정·프로젝트·할일 데이터 저장 (서울 리전 Postgres) |

## 3. 화면 구성

- **상단 바**: 설정 / 프로젝트 관리(추가·삭제) / 빠른 할일 추가 / 이메일로 추가
- **상태 탭**: 전체 / 진행중 / 완료 / 보류 / 취소 — 클릭해서 해당 상태만 모아보기
- **필터**: 프로젝트별, 마감기한별(기한 지남/오늘 마감/7일 이내/기한 없음)로 좁혀보기
- **할일 카드**: 클릭하면 상세 화면 — 이메일 원문, 생성된 프롬프트(다시 복사 가능), 상태 변경 버튼, 상태 변경 이력(타임라인, 길어지면 내부 스크롤)이 모두 보입니다
- **프로젝트 삭제**: "+ 프로젝트" 모달에서 기존 프로젝트를 삭제할 수 있습니다. 삭제해도 그 프로젝트에 속한 할일은 지워지지 않고 "프로젝트 없음" 상태로 남습니다.

### 관련 파일은 "경로만" 등록합니다
파일 자체를 업로드하지 않고, 파일이 있는 **경로(문자열)만** 등록합니다 — DB에는 이 짧은 텍스트만 저장되고 파일 내용은 전혀 저장되지 않습니다. 이렇게 하는 이유는 (1) 자동화 스크립트가 같은 PC에서 돌기 때문에 경로만 있으면 Claude가 직접 그 파일을 열어볼 수 있고, (2) 수동으로 Claude Desktop/Code에 붙여넣을 때도 참고용으로 쓸 수 있기 때문입니다. 이메일 본문에 "첨부", "파일", "문서" 같은 단어나 확장자(`.pdf`, `.docx` 등)가 보이는데 경로를 하나도 등록하지 않으면, 등록 완료 화면과 상세 화면에 "등록 잊으신 것 같아요" 알림이 자동으로 뜹니다.

## 4. 할일 상태 규칙

진행중 / 완료 / 보류 / 취소 네 가지 상태는 **서로 자유롭게 오갈 수 있습니다**. "취소"도 완전 삭제가 아니라 상태 중 하나일 뿐이라, 나중에 다시 "진행중"으로 되돌릴 수 있습니다. 상태가 바뀔 때마다 시간이 자동으로 기록되어, 나중에 "완료까지 며칠 걸렸는지", "몇 번 보류됐는지"를 상세 화면의 타임라인에서 확인할 수 있습니다.

## 5. 마감일 자동 인식 / 제목 자동 생성에 대해

- **마감일 인식**: `2026-09-20`, `9월 20일까지`, `9/20`, `오늘`/`내일`/`모레` 같은 흔한 표현을 규칙 기반으로 찾아냅니다. 완벽하지 않으니, 못 찾으면 즉시 직접 입력을 요청합니다.
- **제목 자동 생성**: 실제 AI(생성형 언어모델)를 호출하는 게 아니라, "인사말 줄은 건너뛰고 첫 번째 의미 있는 문장을 제목으로 쓴다"는 간단한 규칙으로 만듭니다. 상세 화면에서 필요하면 나중에 직접 다듬어 쓸 수 있습니다 (현재는 제목 수정 기능은 없고, 재등록으로 대체 — 필요하시면 추가 제작 가능합니다).

## 6. 설정 — 데스크탑 할일 폴더 경로

상단의 "설정"에서 내 컴퓨터의 폴더 경로(예: `C:\Users\내이름\Desktop\할일`)를 적어두면, 생성되는 프롬프트 안에 "이 경로 아래에 정리해줘"라는 안내 문구로 그대로 들어갑니다. 이 사이트가 실제로 그 폴더에 접근하는 건 아니고, Claude에게 전달할 안내 문구를 미리 채워주는 역할만 합니다.

## 8. 앞으로 확장하고 싶다면

- 제목/요약을 진짜 AI가 만들게 하고 싶다면 → 서버에서 언어모델 API를 호출하는 구조 추가 필요 (API 키를 브라우저에 직접 노출하면 안 되기 때문)
- 파일을 실제로 첨부/열람하고 싶다면 → 별도 파일 저장소(예: 클라우드 스토리지) 연동 필요
- 비밀번호 재설정, 프로필 수정 등은 아직 없음 — 필요하면 추가 제작 가능

## 9. 자동화 — PC가 알아서 Claude에게 넘기기

`automation/watch_and_run.py`를 PC에서 주기적으로 실행하면, 이메일로 등록한 새 할일을 사람이 복사-붙여넣기 하지 않아도 자동으로 `claude -p`(Claude Code 헤드리스 모드)에 넘겨서 처리합니다.

**설정 방법**
1. `automation/.env.automation.example`을 같은 폴더에 `.env.automation`이라는 이름으로 복사
2. 그 파일을 열어 사이트 로그인 아이디/비밀번호를 채워넣기 (이 파일은 git에 올라가지 않습니다)
3. `pip install -r automation/requirements.txt`
4. PowerShell에서:
   ```powershell
   cd "C:\Users\etners\Desktop\ETNS_VIBE\email-task-tracker\automation"
   .\setup_scheduled_task.ps1
   ```
   → "EmailTaskTrackerAutomation"이라는 이름으로 Windows 작업 스케줄러에 등록되어, **5분마다** 새 할일이 있는지 확인하고 자동 처리합니다.

**동작 원리**
- 아직 자동 처리하지 않은, 이메일에서 만든 "진행중" 할일을 찾습니다 (직접 입력한 빠른 할일은 이메일 본문이 없어서 자동 처리 대상이 아닙니다).
- 각 할일마다 웹사이트가 만드는 것과 똑같은 프롬프트를 `claude -p`로 실행합니다.
- 실행이 성공하면 서버에 "자동 처리됨" 표시를 남깁니다 (할일 상세 화면에서 🤖 아이콘으로 확인 가능). 실패하면 표시하지 않고 다음 실행 때 다시 시도합니다.
- **상태(진행중/완료 등)는 절대 자동으로 바꾸지 않습니다** — 검토 후 완료 처리는 여전히 사람이 사이트에서 직접 합니다.

**실행 기록 확인**: `automation/automation.log`에 실행할 때마다 기록이 남습니다.

**등록 취소**:
```powershell
schtasks /delete /tn "EmailTaskTrackerAutomation" /f
```
